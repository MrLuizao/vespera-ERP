# Vespera Hub ERP • Sistema Financiero & Legal (CFO Core)

Plataforma B2B de Dirección Financiera, Tesorería, Blindaje Fiscal SAT y Gobierno Corporativo para Grupos Restauranteros de Alta Gama en México (Vespera Hub ERP).

## Stack Tecnológico
- **Framework:** Nuxt 4 + Vue 3.5 + TypeScript
- **Estilos:** Tailwind CSS (Liquid Glassmorphism / Private Banking Edition)
- **Estado:** Pinia (`useCfoStore`)
- **Gestor de paquetes:** Yarn

## Ejecución
```bash
yarn install
yarn dev
```
